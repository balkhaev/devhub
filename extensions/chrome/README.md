# DevHub для Chrome

Расширение Manifest V3 заменяет страницу новой вкладки Chrome (`Ctrl+T`,
кнопка `+` или новое окно). DevHub отображается внутри неё на весь экран,
а сама вкладка не переходит на `http://127.0.0.1:4700/`. При `Ctrl+T`
фокус остаётся в адресной строке Chrome.

## Установка

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** справа вверху.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку:
   `F:\code\devhub\extensions\chrome`.
4. Если Chrome попросит подтвердить замену новой вкладки, сохраните изменение.
5. Откройте новую вкладку: должен появиться DevHub.

Сборка и установка зависимостей не нужны. Папку расширения после установки
нельзя перемещать или удалять. После изменения файлов нажмите **Обновить**
на карточке расширения.

## Обновление с версии 1.0

На `chrome://extensions` нажмите **Обновить** на карточке DevHub
(круглая стрелка), затем откройте новую вкладку. Уже открытые вкладки
с адресом `127.0.0.1:4700` останутся обычными страницами.

## Как работает

- `chrome_url_overrides.newtab` открывает локальный `newtab.html`.
- DevHub загружается в полноэкранном `iframe`. Скриптов, перенаправления
  верхней страницы, `autofocus` и вызовов `focus()` в расширении нет.
- Вкладка сохраняет поведение новой вкладки Chrome. Настройка запуска
  браузера больше не переопределяется: при выборе «Открывать новую вкладку»
  Chrome использует эту же страницу; восстановление сеанса остаётся настройкой Chrome.
- CSP разрешает только локальный frame DevHub на `127.0.0.1:4700`.
  Sandbox не позволяет содержимому frame перенаправить верхнюю страницу;
  приложения по-прежнему могут открываться в отдельных вкладках.
- Дополнительные разрешения и доступ к другим сайтам не запрашиваются;
  фоновых процессов нет. Chrome может показать подтверждение замены страниц.
- DevHub должен быть запущен через свой трей или `Пульт.cmd`. Расширение
  только открывает адрес и не запускает сервер.
- Новая вкладка в режиме инкогнито остаётся стандартной — это ограничение Chrome.
- Другое расширение новой вкладки или политика организации может помешать
  замене страницы. Отключите конфликтующее расширение или проверьте `chrome://policy`.

Чтобы вернуть прежние страницы, отключите или удалите расширение
на `chrome://extensions`.
