# __PROJECT_NAME__

Рабочая основа браузерной 2D idle-игры: Phaser 3, TypeScript, Vite и Bun. В примере можно собирать кристаллы, нанимать помощников и улучшать мастерскую. Прогресс сохраняется на устройстве, производство продолжается офлайн до восьми часов.

## Разработка

```sh
bun install
bun run dev
```

`dev` обращается к DevHub. Адрес игры, порт и команда Vite указаны в `devhub.json`. Все серверы разработки запускаются из основной папки проекта через DevHub; временная worktree показывает уже интегрированный код.

```sh
bun run check
bun run test
bun run build
bun run worktree status
```

## Устройство игры

- `src/game/engine.ts` — чистая экономика, покупки, проверка сохранений и расчёт офлайн-прогресса. Не зависит от браузера и Phaser.
- `src/game/WorkshopScene.ts` — двухмерная сцена Phaser с процедурной графикой и анимацией.
- `src/main.ts` — интерфейс, управление, автоматическое сохранение и связь с экономикой.
- `src/style.css` — адаптивный интерфейс, доступные HTML-кнопки и индикация состояния.
- `test/engine.test.ts` — проверки баланса, атомарности покупок, часов и восстановления.
- `server/handler.ts` — раздача собранной игры с security-заголовками и маршрутом `/health`.

Содержимое сохранения находится в `localStorage` под ключом `__PROJECT_NAME__:save:v1`. Это локальная одиночная игра. Для общего аккаунта, серверной экономики или синхронизации устройств нужен отдельный API. При изменении схемы сохранения добавьте явную миграцию версии.

## Production

```sh
bun run build
bun run start
```

Самостоятельный сервер раздаёт `dist` на `0.0.0.0:3000`; адрес настраивается через `HOST` и `PORT`. Для запуска нужны только Bun, `dist`, `server.ts` и папка `server`. DevHub и Vite в production не требуются.

Dockerfile собирает игру и переносит только эти файлы в финальный контейнер:

```sh
docker build -t __PROJECT_NAME__ .
docker run --rm -p 3000:3000 __PROJECT_NAME__
```

Новый проект начинает в MVP с `remote: null`: проверенные изменения остаются в локальном `main`. Публикация на внешний сервис настраивается отдельно.
